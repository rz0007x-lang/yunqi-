# 云栖连续寺院地图 v1.0

## 坐标范围

- 世界范围：X `-40～40`，Z `-50～60`，约 80×110 米。
- 北侧为主殿，南侧为山道入口；用户沿 Z 轴负方向进入寺院。
- 当前线上山门位于 Z≈25、主殿位于 Z≈0，后续连续地图沿用这一方向并扩大两侧空间。

## 用户主路线

1. 用户在山道入口出现，第一眼看到远处山门灯火。
2. 沿 3.6 米宽石径进入山门，环境音从山风过渡到庭院水声。
3. 穿过山门后看见完整主云庭、左右偏殿和北侧主殿。
4. 用户可以直行进入主殿，也可以先去竹林、水庭或偏殿。
5. 靠近主殿坐垫后出现“入座”，坐下后镜头进入仪式构图。

## 分区加载

- `zone-entry`：山道、山门、近景松竹、第一组灯笼。
- `zone-courtyard`：云庭、石桥、水池、偏殿外观。
- `zone-hall`：主殿、坐垫、角色和仪式核心。
- `zone-west`：竹林、静坐亭、西偏殿。
- `zone-east`：数字人偏殿、钟鼓区、东偏殿。

进入一个区域时加载当前区和前方相邻区；离开两个区域后才释放最远区域，避免用户转身时反复加载。
