# Spec: 模块化场景资源包 v0.1（待确认）

## 原始输入

原话全量在 [modular-scene-pack.raw-input.md](./modular-scene-pack.raw-input.md)；本轮新增 RAW-01～RAW-02。

## 意图

当前云栖只有山门和大殿两个质量较高的建筑，周围环境仍然像临时布景。需要按一张完整地图制作可重复组合的建筑、自然环境和寺庙道具，让后续连续行走世界可以直接使用，而不是每次临时生成一个孤立模型。

## 非目标

- 当前不制作角色、动作和真实多人。
- 当前不把全部资产一次性加载进正式网页。
- 并发不适用：同一资产不会由多个生成任务共同写入同一个正式版本。
- 多端不适用：资源包只有一份，由同一套 Three.js 网页使用。
- 账号切换不适用：资产生产不向终端访客展示账号数据。
- 客户端工具名称和图标不适用：本功能不新增面向访客的工具入口。

## 验收标准

| ID | 级 | Given | When | Then | 落点 | 状态 | 证据 |
|---|---|---|---|---|---|---|---|
| AC-01 | [核] | 已有山门和大殿作为视觉基准 | 查看视觉规范 | 能看到统一的颜色、材质、比例、朝向和禁止项 | 视觉规范文档 |  |  |
| AC-02 | [核] | 寺院被拆成山门、云庭、主殿和两个侧区 | 查看地图 | 每个区域的位置、主要路线和需要的资产都有明确记录 | 地图文档 |  |  |
| AC-03 | [核] | 需要制作建筑、自然环境和道具 | 查看资产清单 | 每件资产都有唯一 ID、用途、尺寸、优先级、生成方式和状态 | 资产清单 |  |  |
| AC-04 | [核] | 第一批资产准备生成 | 查看生成批次 | 每项都有继承统一风格的提示词、面数档位和输出要求 | 提示词库、批次文件 |  |  |
| AC-05 | [核] | 某个生成任务失败或只完成一部分 | 更新任务状态 | 失败资产不会标记为可接入，成功资产可以单独进入检查 | 资产清单 |  |  |
| AC-06 | [边] | 生成任务中断后重新开始 | 再次执行同一资产 | 沿用原资产 ID，并新增版本记录，不产生两个正式身份 | 资产清单 |  |  |
| AC-07 | [核] | 资产准备进入正式场景 | 执行接入前检查 | 比例、原点、朝向、材质、LOD、压缩和文件大小全部有结果 | 资产验收记录 |  |  |
| AC-08 | [边] | 新资源尚未加载或加载失败 | 用户进入当前线上场景 | 仍然显示现有山门、大殿或程序化替代，不出现空白世界 | Three.js 场景 |  |  |
