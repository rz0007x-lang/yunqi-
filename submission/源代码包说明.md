# 云栖电子禅堂源代码包说明

此压缩包是比赛提交用的精简工程，不包含约 4 GB 的 Lux3D 原始下载包、被淘汰的候选资产和重复构建产物。

## 包含内容

- `index.html`、`src/`、`package.json` 和构建脚本
- 当前运行所需的 GLB、纹理和 LOD 资产
- 资产 `manifest.json`、生成批次、提示词与验收记录
- 关键过程截图和效果截图
- 部署配置与项目说明

## 本地运行

```bash
python3 -m http.server 4173
```

浏览器打开 `http://127.0.0.1:4173`。

也可以安装依赖后构建：

```bash
npm install
npm run build
```

## 重要边界

- 当前多人同步使用 `BroadcastChannel`，用于同源浏览器多标签页验证。
- 页面中的环境来客不是跨设备真实在线用户。
- 生产多人版本需要替换为 WebSocket 房间服务，并由服务端处理座位占用、心跳和断线恢复。
