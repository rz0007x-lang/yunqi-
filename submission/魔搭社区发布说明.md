# 魔搭社区发布说明

## 项目名称

云栖电子禅堂：AI 3D 可漫游静修空间

## 项目摘要

云栖电子禅堂是一个运行在浏览器中的实时 3D 寺院体验。项目以 Aholo Lux3D 生成的 PBR 建筑、环境、法器和绑骨角色为核心资产，使用 Three.js 完成山门、云庭、大殿三段连续空间，以及角色移动、相机环绕、夜景光照、动态水面、骨骼动画和仪式交互。

## 主要功能

- 从山门外连续行走至云庭和大殿。
- 第一人称、第三人称和高位远景切换。
- 合掌、礼拜、念珠、木鱼和静坐。
- 52 关节小和尚角色与四项专用仪式动画。
- PBR 念珠、木鱼、黄铜佛像、山门、围墙、石桥和莲花等资产。
- 程序化环境音、钟声、木鱼声和念珠反馈。
- 浏览器多标签页本地共处演示，为后续 WebSocket 房间保留状态接口。

## 运行方式

项目为静态网页，使用 ES Module 加载 Three.js。下载源码后，在项目目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173`。也可以运行构建脚本后部署 `dist` 目录。

## 技术栈

Aholo Lux3D  Three.js  WebGL  JavaScript  GLB  PBR  Meshopt  Web Audio  BroadcastChannel

## 说明

页面中的环境和尚和氛围人数用于单人体验的现场感。当前多人同步仅支持同源浏览器多标签页演示，不代表跨设备真实在线。生产多人版本计划使用 WebSocket 房间、服务端座位仲裁和断线恢复。
