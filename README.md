# 云栖 · 电子禅堂

一个从韩国 Sansa 在线寺庙的产品方法中获得启发、使用原创视觉与程序化 3D 模型实现的网页体验。

## 已实现

- 程序化 3D 大殿、山景、灯笼、坐垫与低多边形小行者
- 点击空坐垫入座、起身换位
- 合掌、礼拜、木鱼、108 念珠、1/3/5 分钟静坐
- Web Audio 程序化环境音、钟声、木鱼与念珠反馈
- 匿名随机法号与无聊天设计
- BroadcastChannel 多标签页同步；同一浏览器打开多个标签页即可验证状态同步
- 15 名环境来客与动作模拟，使单人访问也保有现场感
- 桌面与手机响应式界面

## 本地运行

仓库包含运行所需的模型、纹理和构建脚本。推荐先生成完整静态站，再启动本地服务：

```bash
node scripts/build.mjs
python3 -m http.server 4173 --directory dist
```

打开 http://127.0.0.1:4173 。Three.js 使用 CDN ES Module，需要网络连接。`submission/` 中保留报告与录制脚本、提交文案和字幕；视频、报告导出件、缓存及重复源码压缩包不纳入 Git。

这是一个无构建静态站，Three.js 通过标准 ES Module 加载。任意静态服务器均可运行：

```bash
python3 -m http.server 4173
```

如果需要 Vite 打包，也保留了可选配置：

```bash
npm install && npm run build
```

## 生产多人化

当前 `src/presence.js` 使用 BroadcastChannel 作为零后端演示适配器。生产环境可保持相同接口，将其替换为 WebSocket 房间服务：

1. 进入时由网关分配 `room`、`instance` 和 `region`。
2. 服务端广播快照以及 `move / seat / action / leave` 增量事件。
3. 坐垫占用必须由服务端原子确认，避免多人抢座。
4. 心跳超时后回收座位；断线重连时使用短期 visit token 恢复。
5. 每房建议 30～100 人；远端角色使用 LOD、实例化与动作快照压缩。

## 原创与参考边界

项目复用了“匿名角色、固定坐垫、无聊天共处、少量仪式动作”的产品结构，但没有下载或复制 Sansa 的品牌、代码、GLB 模型、纹理、音频与文字素材。
