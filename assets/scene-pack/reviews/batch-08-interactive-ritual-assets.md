# Batch 08 可闭合山门与实体法器验收

## 结论

`ARCH-013`、`PROP-012`、`PROP-013` 已完成生成、结构检查、LOD、场景替换和浏览器回归。后续山门按用户确认升级为 `ARCH-014` 古庙木门；念珠与木鱼改为只在底部交互弹窗中显示，不再摆放在佛像前。

## ARCH-013 / ARCH-014 可闭合山门

- Lux3D 任务：`7995325`。
- 单扇源模型包含厚木板、横梁、边框、铜钉与左侧铰链带；没有门框、墙体或第二扇门。
- 运行时复制并镜像为左右门扇，各自绕外侧铰链旋转。
- 山门视角自动闭合；进入云庭和大殿后平滑开启。浏览器诊断 `gateDoors=true`，闭合值为 `0`，开启值为 `1`。
- LOD1：31,720 triangles / 7,049,180 bytes；LOD2：18,262 triangles / 6,977,936 bytes。
- `ARCH-014` 取代 `ARCH-013`：旧木板、黑铁铰链和青铜门环风格通过用户确认；LOD1 为 43,702 triangles / 1,255,148 bytes，底部生成底板下沉至现有门槛内。

## PROP-012 实体念珠

- Lux3D 任务：`7995324`。
- 模型具有多圈木珠、母珠、连续绳线和流苏，不再是抽象光环。
- 大殿内安置在佛像左前方的木制挂架；每次“转动一珠”会触发 3D 念珠的轻微旋转。
- 点击底部“念珠”会弹出真实 GLB 念珠查看器；支持拖动旋转、点击模型或按钮转动一珠，并保留 0–108 计数和完成提示。
- LOD1：43,960 triangles / 10,240,456 bytes；LOD2：25,642 triangles / 10,120,860 bytes。

## PROP-013 实体木鱼

- Lux3D 任务：`7995323`；部件拆分任务：`7995499`。
- 源模型包含中空雕刻木鱼、发声槽、红色织物软垫与木槌。
- 拆分后保留四个命名节点：鱼身、软垫、原生木槌和软垫外圈；运行时直接驱动 `wooden-fish-mallet`，不再叠加程序化假槌。
- 点击底部“木鱼”会弹出真实 GLB 木鱼查看器；支持拖动旋转，点击模型或“敲击木鱼”按钮时，原生木槌动画与现有木鱼声音和小和尚动作同步。
- LOD1：32,412 triangles / 9,875,008 bytes；LOD2：18,520 triangles / 9,793,532 bytes。

## 回归检查

- 山门关闭与开启状态均能达到目标值，没有控制台错误。
- 大殿佛像、小和尚、座位选择、合掌、礼拜、静坐与声音系统未被破坏。
- 新增资产在移动端窄视口中仍可见；念珠和木鱼分别位于佛像左右前方。
- 本批 LOD 完成了几何简化；由于本机原生 WebP 版 `gltfpack` 不可用，新增三件资产暂时保留源纹理，因此 LOD2 的下载体积主要仍由纹理决定。
